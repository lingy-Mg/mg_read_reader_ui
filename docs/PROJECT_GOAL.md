# 项目目标

`novel_reader_ui` 是一个可复用的 Flutter 文本小说阅读器插件，而不是完整小说平台 App。

首版目标：

- 宿主通过异步接口注入书籍信息、章节目录和稳定段落正文。
- 默认从索引 `-1` 的书籍信息预览进入，通过全书索引接口随机定位章节。
- 插件完成横向分页、纵向滚动、章节切换、目录、书签和阅读设置。
- 阅读进度、设置和书签由宿主持久化，插件不绑定数据库或账号系统。
- Android 和 Windows 原生实现负责活动阅读期间的屏幕常亮。
- 正文只按需保留当前章与下一章，分页引擎只排版当前章；上一章按需重载。
- 共享生命周期和会话运行时可以在未来供漫画阅读器复用。

不在首版范围：书架、书城、详情、账号、付费、推荐、文件解析、听书、仿真卷页和评论 UI。

详细架构和长期一致性规则以根目录 `AGENTS.md` 为准。
